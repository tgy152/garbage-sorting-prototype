# 核心换算关系

## 一、冷冻水侧：冷负荷—水流量—供回水温差

能量守恒关系：

```
Q = G · ρ · c · Δt
```

其中 Q 为冷负荷（kW），G 为体积流量（m³/h），ρ 为水密度（取 1000 kg/m³），
c 为水的比热容（取 4.187 kJ/(kg·K)），Δt 为供回水温差（℃）。

把 m³/h 换算为 kg/h 并统一到 kW 后，可得到工程上常用的简化式：

```
G(m³/h) = Q(kW) / [1.163 × Δt(℃)]
```

**关键点**：系数 1.163 已经包含了"1000 kg/m³ ÷ 3600 s/h × 4.187"三项。
学生最常见的错误是直接写 `G = Q / (4.18 × Δt)`，漏掉单位换算，
算出的流量只有正确值的约 1/3.6。

**示例**：冷负荷 45 kW，供回水 7 ℃ / 12 ℃（Δt = 5 ℃）

- 正确：G = 45 ÷ (1.163 × 5) ≈ 7.74 m³/h
- 典型错误：G = 45 ÷ (4.18 × 5) ≈ 2.15 m³/h

按错误流量选出的水泵与水管管径会严重偏小，实际运行时达不到设计温差。

## 二、空气侧：冷负荷—送风量—送风温差

```
Q(kW) = L(m³/h) × ρ × c × Δt / 3600
```

取空气密度 ρ = 1.2 kg/m³、比热容 c = 1.005 kJ/(kg·K)，可得：

```
L(m³/h) ≈ 2985 × Q(kW) / Δt(℃)
```

**示例**：冷负荷 45 kW，送风温差 8 ℃
L ≈ 2985 × 45 ÷ 8 ≈ 16791 m³/h

送风温差取值越大，所需送风量越小、风管断面越小，但过大会导致送风直吹感明显、
室内温度分布不均。

## 三、人员新风量

```
新风量(m³/h) = 人员数量 × 人均新风量[m³/(h·人)]
```

人均新风量属于卫生要求，民用建筑主要房间不应低于 30 m³/(h·人)
（具体条文号请核对现行规范）。调整人均新风量后，新风总量与新风负荷都必须联动重算。

## 四、水泵扬程

```
水泵扬程 = 最不利环路阻力 + 末端设备阻力 + 富余量
```

两点最容易出错：

1. 只计算最不利环路阻力，漏掉末端设备（表冷器、风机盘管、电动阀）的阻力；
2. 没有留富余量。工程上通常取计算总阻力的 1.05~1.2 倍。

扬程选小会导致实际水流量达不到设计值，房间达不到设计温度，是课程设计中的高频错误。
