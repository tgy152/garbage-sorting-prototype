# 实验室安全总则（示例数据）

## 一、准入要求

1. 所有进入实验室的人员必须完成安全培训并通过考核，考核合格证有效期两年。
2. 首次进入实验室须由实验室安全责任人带领熟悉应急设施位置，包括洗眼器、紧急淋浴、灭火器、急救箱与总电源开关。
3. 实验室内禁止饮食、吸烟、存放个人食品与饮料。
4. 实验期间必须全程佩戴护目镜与实验服，长发须束起。

## 二、巡检频次与记录

1. 实验室安全巡检员每周巡检不少于 3 次，每次巡检须填写《实验室安全检查记录表》。
2. 巡检重点为：危化品存放、气瓶固定、用电安全、消防通道畅通、废弃物分类。
3. 发现重大隐患应当场停止相关实验，并在 2 小时内上报实验室安全责任人。
4. 一般隐患应在 3 个工作日内完成整改，整改结果须由巡检员复核确认。

## 三、用电与设备安全

1. 大功率设备须使用专用插座，禁止使用多级串联插线板。
2. 离开实验室前须关闭非必要设备电源，长时间运行的设备须张贴"运行中"标识。
3. 烘箱、马弗炉等高温设备周围 0.5 米内不得堆放可燃物。
4. 设备故障须立即断电并挂"禁止合闸"警示牌。

## 四、气瓶管理

1. 气瓶必须直立固定，使用防倒链或气瓶柜，禁止平放。
2. 可燃气体气瓶与助燃气体气瓶间距不得小于 5 米。
3. 气瓶须定期检验，超过检验期的气瓶不得使用。
4. 搬运气瓶须使用专用推车，禁止滚动或肩扛。
