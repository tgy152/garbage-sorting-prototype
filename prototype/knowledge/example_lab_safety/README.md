# 示例知识库（虚构数据，仅用于跑通流程）

> **注意**：本目录下的文档为演示用虚构内容，**不得直接用于参赛材料**。
> 正式参赛时请替换为真实调研获得的规范、手册、访谈记录等，并在方案书中注明来源。

支持的格式：`.md` `.txt` `.csv` `.json`，安装 `pypdf` 后额外支持 `.pdf`。

替换步骤：

1. 把你的真实文档放进 `knowledge/<你的场景ID>/`
2. 运行 `python -m scripts.smoke_test --scene <你的场景ID>` 重建索引
3. 或直接在 Gradio 界面「知识库」页签上传文件并点击重建
