# 地区标准差异说明

## 一、为什么必须区分地区

中国各城市的垃圾分类标准在**类别名称**和**部分物品归属**上并不统一。
同一件垃圾在不同城市可能需要投进不同颜色的桶，
这是投放引导系统必须处理的问题，也是"全国统一答案"类工具会出错的原因。

## 二、类别名称对照

| 通用四分类 | 上海叫法 | 北京 / 广州叫法 |
| --- | --- | --- |
| 厨余垃圾 | **湿垃圾** | 厨余垃圾 |
| 其他垃圾 | **干垃圾** | 其他垃圾 |
| 可回收物 | 可回收物 | 可回收物 |
| 有害垃圾 | 有害垃圾 | 有害垃圾 |

**注意**：上海的"湿垃圾"并不等于"湿的垃圾"，
北京的"干垃圾"也不等于"干的垃圾"，它们是类别名称而非状态描述。
这是跨城市生活的人最容易混淆的一点。

## 三、存在归属差异的典型物品

| 物品 | 差异情况 |
| --- | --- |
| 普通碱性干电池 | 低汞化后多数城市按其他垃圾；部分城市仍要求投有害垃圾 |
| 大棒骨、椰子壳 | 多数城市按其他垃圾，少数城市列入厨余 |
| 一次性纸杯 | 多数城市按其他垃圾，个别城市有专门回收渠道 |
| 塑料袋 | 部分城市鼓励将干净塑料袋投可回收，部分城市统一要求其他垃圾 |

## 四、系统的处理方式

本系统把"地区标准"作为可切换配置：

- 切换地区时，类别**名称**会本地化（例如自动把"厨余垃圾"显示为"湿垃圾"）；
- 存在归属差异的物品会在引导中额外标注差异说明；
- 所有引导结论都附带"以所在城市现行分类目录为准"的提示。

## 五、使用提醒

本知识库中的归属结论为教学演示用通行做法。
正式参赛与上线使用前，必须对照目标城市的现行分类目录逐条核实，
并在系统中注明依据的目录版本与发布日期。
