# 分类总则与判定顺序

> ⚠️ 各地分类标准存在差异：上海使用"湿垃圾 / 干垃圾"，北京、广州使用"厨余垃圾 / 其他垃圾"。
> 本文件中的类别归属为**教学演示用通行做法**，正式使用请以所在城市现行分类目录为准。

## 一、四分类基本口径

| 类别 | 常见内容 | 投放要求 |
| --- | --- | --- |
| 可回收物 | 纸类、塑料、玻璃、金属、织物 | 清空内容物 → 简单冲洗 → 沥干 → 压扁 |
| 有害垃圾 | 充电电池、过期药品、含汞物品、灯管 | 保持包装完整，防止破损渗漏 |
| 厨余垃圾（湿垃圾） | 剩饭剩菜、果皮果核、茶叶渣 | 沥干水分，去除包装物 |
| 其他垃圾（干垃圾） | 纸巾、一次性餐具、污染塑料、大棒骨 | 沥干水分后投放 |

## 二、判定顺序（按此顺序判断，能避开大部分误投）

1. **先看有没有害**：含汞、含药、含充电电池 → 有害垃圾。
2. **再看能不能吃**：食物本身、果皮果核 → 厨余垃圾。
3. **再看能不能回收**：**必须同时满足**下面三个条件：
   - 材质属于可回收清单（纸、塑料、玻璃、金属、织物）；
   - **干净、未污染**；
   - 有回收利用价值。
4. **剩下的都是其他垃圾**。

## 三、最容易被忽略的一条

> **"属于可回收材质" ≠ "可以投可回收物"。**

被油污污染的塑料餐盒、沾了糖分的奶茶杯、渗了汤的纸箱，
材质上都是可回收的，但**实际投放时属于其他垃圾**。

现有查询工具大多只回答第 3 步的"材质归属"，却不说第 3 步的"干净"条件，
这正是投放点误投率最高的原因。

## 四、投放前的四个标准动作

| 动作 | 适用对象 | 目的 |
| --- | --- | --- |
| 倒空 | 所有带内容物的容器 | 避免渗漏、异味、污染同桶垃圾 |
| 冲洗 | 可回收的塑料、玻璃、金属容器 | 达到"干净"这一可回收前提 |
| 沥干 | 厨余垃圾、冲洗后的可回收物 | 降低含水率，减少运输渗漏 |
| 拆解 | 复合垃圾 | 让每个部件进入正确的桶 |

## 五、隐私与安全提醒

- 快递面单承载姓名、电话、住址，投放前应撕碎个人信息部分；
- 破碎玻璃、针头等尖利物应包裹后再投放，避免划伤保洁人员；
- 含汞物品破损后应密封包裹，不要用手直接接触。
