# 复合垃圾拆解原则

## 一、什么是复合垃圾

由两种及以上材质构成、或同时包含物品与内容物的垃圾。
最常见的五类：

1. 含液体的饮品容器（奶茶杯、咖啡杯、未喝完的饮料瓶）
2. 含食物残渣的餐盒（外卖餐盒、泡面桶、食堂打包盒）
3. 含附属件的包装（带胶带与面单的快递箱）
4. 由多种材质组成的小物件（中性笔、耳机线）
5. 个人防护用品（口罩、湿巾及其包装）

## 二、拆解的三个步骤

### 第一步：分离内容物

液体倒入水槽，固体食物倒入厨余桶。

为什么必须做：内容物渗漏会污染同桶的其他垃圾，
让本来能回收的东西也失去回收价值。

### 第二步：按材质拆分部件

把杯子与杯盖、纸箱与胶带、餐盒与筷子分开。

为什么必须做：不同材质的处置路径不同，
捆在一起投放会让整件物品只能按最低价值的那一类处理。

### 第三步：判断每个部件是否需要预处理

塑料、玻璃、金属容器需要冲洗到"无明显残留"才可回收；
纸箱需要压平并保持干燥。

## 三、条件化投放：最容易出错的地方

复合垃圾的投放结论常常是**有条件的**，而不是单一答案。

| 物品 | 条件 | 结论 |
| --- | --- | --- |
| 塑料餐盒 | 油污能洗净 | 可回收物 |
| 塑料餐盒 | 油污严重、无法洗净 | 其他垃圾 |
| 奶茶杯身 | 冲洗干净 | 可回收物 |
| 奶茶杯身 | 残留糖分奶渍 | 其他垃圾 |
| 塑料袋 | 干净无异味 | 可回收物 |
| 塑料袋 | 沾染油污 | 其他垃圾 |
| 纸隔热套 | 干燥洁净 | 可回收物 |
| 纸隔热套 | 沾有饮品 | 其他垃圾 |

**引导系统必须把条件说清楚。**只给单一结论会直接导致误投，
这是现有查询工具最主要的能力缺口。

## 四、拆解引导的输出格式

一次合格的引导应包含：

1. 总体结论（是否为复合垃圾、需要拆成几部分）
2. 逐部件的「投哪个桶」+「投之前做什么」
3. 该物品最容易投错的地方
4. 类别依赖条件时的条件说明
