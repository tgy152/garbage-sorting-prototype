# 数据大屏（静态演示版）

参考可视化大屏的形态做的一块 16:9 展示页：深色底、发光描边、中间一个 3D 主视觉，
四周挂六块数据面板。**内容全部是本项目跑出来的真实数据，没有演示性假数据。**

## 怎么打开

四种方式，任选一种，都不需要联网：

1. **双击 `打开大屏.cmd`**（最省事：会直接用 Edge / Chrome 打开单文件版）
2. 双击 `数据大屏-单文件版.html`（所有代码和库都内联在这一个文件里，最不容易出问题）
3. 双击 `index.html`（标准版，靠同目录的 css / js / vendor）
4. 浏览器里打开 `http://127.0.0.1:7860/screen/`（需要原型服务在跑；手机上走公网地址也能看）

打开后：`F11` 全屏，等比缩放到任意屏幕；拖动中间模型可以旋转视角；点右下角的提示文字重播拆解动画。

### 如果打不开

页面已经按"没有 WebGL 也要能看"重写过：

- **浏览器没启用 WebGL**（硬件加速关掉、显卡驱动异常、远程桌面等）：三维动画会自动换成 2D 示意，四块数据面板、六个部件小卡照常显示，右上角会写明当前是 2D 模式
- **双击没反应 / 被别的软件接管了 .html 关联**：用 `打开大屏.cmd`，它会显式调用 Edge 或 Chrome
- **拷到别的电脑只剩一个文件**：用 `数据大屏-单文件版.html`

改完源码后重新打包单文件版：`node build-single.mjs`

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `screen.css` | 样式（配色沿用苔绿 / 沙 / 赭石，四分类桶色与方案书、答辩 PPT 一致） |

## 和现有材料的关系

这块大屏是**独立的加分展示页**，不改动已经定稿的东西：
作品方案书、答辩 PPT、作品介绍页（`landing/`）、原型（`prototype/`）都保持原样。

## 后面怎么接真实接口

现在所有数字都写在 `screen.js` 顶部的常量里（`BIN_DATA`、`GUIDE_METRICS`、`QA`、`ITER`）。
要变成实时大屏，把这几处常量换成对原型的请求即可，后端不用改：

| 常量 | 可换成 |
|---|---|
| `BIN_DATA` | 规则库对最新一批照片的判定结果 |
| `GUIDE_METRICS` / `QA` | `python eval/run_waste_eval.py`、`run_eval.py` 产出的汇总 JSON |
| 顶栏「数据为静态快照」 | 改成实际刷新时间 |

## 已知边界

- 静态快照，不连后台，所以顶栏写明「数据为静态快照」，避免误读成实时数据
- 有害垃圾桶这一件物品用不上，但桶位照实摆出来，正好说明是逐部件判定
